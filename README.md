# متجر ولاء فاضل: واجهة Front-end

واجهة متجر عربية (RTL) متجاوبة للجوال والكمبيوتر، مبنية بـ HTML وCSS وJavaScript فقط، **دون خطوة بناء ودون Backend**. المجلد `public/` هو الموقع نفسه، جاهز للرفع كما هو.

> نسخة عرض لتصميم الواجهة. السلة تجريبية، ولا يوجد دفع فعلي. زر «إتمام الطلب» يفتح متجر ولاء الأصلي.

## ما في الواجهة

- **الرئيسية**: الواجهة الأولى، «إيش تحتاجي اليوم؟» بأربعة مداخل، عن ولاء، الجلسات المسجلة، اللقاءات الحضورية، الجلسات الخاصة، أكتبي واكتشفي، آراء الزائرات، المعرفة، الأسئلة الشائعة.
- **صفحات الأقسام** (`#catalog/...`): تصفية بالقسم، بحث بالاسم، ترتيب بالسعر أو الاسم.
- **صفحة كل منتج** (`#product/<id>`): التفاصيل، المعلومات الأساسية، الأسئلة، شريط شراء ثابت على الجوال، منتجات مشابهة.
- **عن ولاء**، **المعرفة والمصادر**، **الأسئلة الشائعة**.
- **البحث** (نافذة منبثقة) و**السلة التجريبية** (تُحفظ في متصفح الزائرة فقط).
- 32 منتجًا: 25 جلسة مسجلة، 3 لقاءات حضورية، 4 جلسات خاصة.

التنقل يعتمد على `#` في الرابط (مثل `.../#catalog/recorded`)، لذلك تعمل كل الصفحات الداخلية على أي استضافة دون إعدادات إضافية، وحتى عند فتح رابط صفحة داخلية مباشرة.

## هيكل المشروع

```
walaa-store/
├─ public/                ← الموقع (هذا ما يُنشر)
│  ├─ index.html          الهيكل، القائمة، التذييل، نافذتا البحث والسلة
│  ├─ theme.css           كل التنسيقات؛ الألوان والخطوط متغيرات في أعلى الملف
│  ├─ data.js             كل المحتوى: المنتجات والأسعار والتواريخ والأسئلة والآراء
│  ├─ app.js              العرض والتنقل والبحث والتصفية والسلة
│  ├─ favicon.svg         أيقونة التبويب
│  └─ assets/*.jpg        الصور
├─ source/                صورتا التصميم الأولى (البنر)
├─ tools/
│  ├─ serve.ps1           معاينة محلية دون أي تثبيت (ويندوز)
│  ├─ bundle.ps1          يبني ملفًا واحدًا للمعاينة يُرسل للعميل
│  └─ make-assets.ps1     يقص صور ولاء من مجلد الدرايف إلى public/assets
├─ scripts/serve.mjs      معاينة محلية لمن لديه Node.js
├─ .github/workflows/pages.yml   نشر تلقائي على GitHub Pages
├─ netlify.toml / vercel.json    إعدادات Netlify وVercel
└─ package.json
```

## التشغيل محليًا

**الطريقة الأولى (ويندوز، دون تثبيت شيء):** افتحي PowerShell داخل مجلد `walaa-store` ثم:

```bash
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
```

وافتحي http://127.0.0.1:4174 . لإيقاف الخادم: `Ctrl + C`.

**الطريقة الثانية (إذا ثبّتِّ Node.js 18 أو أحدث):**

```bash
npm run dev
```

لا توجد مكتبات تحتاج تثبيتًا، فلا حاجة لـ `npm install`.

> فتح `public/index.html` بضغطة مزدوجة يعمل غالبًا، لكن الخادم المحلي أدق في محاكاة الموقع المنشور.

## ملف معاينة واحد للعميل

لإرسال نسخة تُفتح بضغطة مزدوجة دون رفع (الصور والتنسيقات داخل ملف واحد):

```bash
powershell -ExecutionPolicy Bypass -File tools/bundle.ps1
```

ينتج `walaa-store-preview.html` في جذر المشروع (نحو 1.7 ميجابايت). الخطوط تُحمّل من Google Fonts فتحتاج اتصالًا بالإنترنت. الملف لا يُرفع إلى GitHub (مذكور في `.gitignore`)، أعيدي بناءه بعد أي تعديل.

## التعديل

| ما تريدين تغييره | أين |
|---|---|
| اسم منتج، سعره، وصفه، تاريخ لقاء | `public/data.js` ← `products` |
| إضافة منتج | سطر جديد في `products` بالشكل `['المعرّف', 'الاسم', السعر, 'القسم', 'الوصف', 'التاريخ للقاءات']`. القسم: `recorded` أو `group` أو `private` أو `journal` أو `affirmation` |
| سعر غير معروف | اكتبي `null`؛ يظهر «السعر في المتجر» ويختفي زر السلة |
| تفاصيل إضافية لمنتج (المدة، طريقة الوصول) | `public/data.js` ← `details` |
| الأسئلة الشائعة، الآراء، المداخل الأربعة | `public/data.js` ← `faqs` و`testimonials` و`entries` |
| الألوان والخطوط والمسافات | أعلى `public/theme.css` داخل `:root` |
| نصوص الصفحة الرئيسية وعن ولاء | `public/app.js` ← الدالتان `home()` و`aboutPage()` |
| القائمة والتذييل | `public/index.html` |
| صورة | استبدلي الملف في `public/assets/` بالاسم نفسه، أو نزّلي مجلد الدرايف إلى `source/drive/` وعدّلي القص في `tools/make-assets.ps1` ثم شغّليه |

**ألوان الهوية:** البنفسجي `#502D4E` (الأزرار)، الأوركيد `#CFACCD` (الإطارات)، الأبيض الدافئ `#FFFAF5`، اللافندر `#F5E6F3`، الخوخي `#FFF1E6`، والمرجاني `#E97E57` للمسات الصغيرة.

**رابط المنتج الأصلي:** يُبنى تلقائيًا من المعرّف: `https://walaafadel.com/p<المعرّف>`.

## الرفع إلى GitHub

المستودع يكون **مجلد `walaa-store` نفسه** (فيه `.github` و`public`)، لا المجلد الأعلى.

### دون سطر أوامر (GitHub Desktop)

1. ثبّتي [GitHub Desktop](https://desktop.github.com/) وسجّلي الدخول من داخله (لا تشاركي كلمة المرور أو أي رمز وصول مع أحد).
2. **File ← Add local repository** واختاري مجلد `walaa-store`. إن ظهر أنه ليس مستودعًا اضغطي **create a repository** واتركي الفرع `main`.
3. اكتبي رسالة في خانة Summary (مثل: «النسخة الأولى من الواجهة») ثم **Commit to main**.
4. **Publish repository**، اختاري الاسم (مثلًا `walaa-store`)، وحدّدي إن كان خاصًا أو عامًا.

### بسطر الأوامر (بعد تثبيت [Git](https://git-scm.com/download/win))

أنشئي مستودعًا فارغًا على github.com (دون README)، ثم داخل مجلد `walaa-store`:

```bash
git init -b main
```

```bash
git add .
```

```bash
git commit -m "النسخة الأولى من واجهة متجر ولاء فاضل"
```

```bash
git remote add origin https://github.com/<اسم-المستخدم>/walaa-store.git
```

```bash
git push -u origin main
```

عند أول `push` تفتح نافذة تسجيل دخول GitHub في المتصفح؛ لا حاجة لكتابة كلمة مرور في الطرفية.

## النشر والحصول على رابط

الموقع ثابت، فأي خدمة من الثلاث تعمل. الأسهل للمشاركة مع العميل:

### GitHub Pages (مجاني، مرتبط بالمستودع)

1. بعد رفع المشروع: في صفحة المستودع **Settings ← Pages**.
2. في **Source** اختاري **GitHub Actions**.
3. افتحي تبويب **Actions**؛ سيعمل «Deploy to GitHub Pages» تلقائيًا (أو اضغطي **Run workflow**).
4. بعد دقيقة تقريبًا يظهر الرابط في **Settings ← Pages**، بالشكل: `https://<اسم-المستخدم>.github.io/walaa-store/`

كل `push` جديد على `main` يحدّث الموقع تلقائيًا. ملاحظة: Pages في المستودعات الخاصة يحتاج حسابًا مدفوعًا؛ في الحساب المجاني اجعلي المستودع عامًا.

### Netlify (أسرع طريقة دون GitHub)

1. ادخلي https://app.netlify.com/drop وسجّلي الدخول.
2. اسحبي مجلد **`public`** (وليس `walaa-store`) وأفلتيه في الصفحة.
3. يظهر رابط فوري بالشكل `https://<اسم-عشوائي>.netlify.app`، ويمكن تغيير الاسم من **Site configuration ← Change site name**.

أو اربطي المستودع من **Add new site ← Import an existing project**؛ الإعدادات تُقرأ من `netlify.toml`.

### Vercel

**Add New ← Project**، اختاري المستودع، واتركي الإعدادات كما هي (تُقرأ من `vercel.json`: لا بناء، والمجلد `public`). الرابط بالشكل `https://walaa-store.vercel.app`.

### التحقق بعد النشر

افتحي الرابط وجرّبي: الصور في الرئيسية، الانتقال بين الأقسام، فتح منتج، البحث، الإضافة إلى السلة، وفتح رابط صفحة داخلية مباشرة (مثل `.../#catalog/private`) في تبويب جديد. ثم جرّبي من الجوال.

## ما زال تجريبيًا أو بانتظار بيانات

- **السلة تجريبية**: تُحفظ في متصفح الزائرة فقط، ولا تُرسل لأي نظام. «إتمام الطلب» يفتح https://walaafadel.com/ ولا ينقل محتوى السلة.
- **الأسعار والمواعيد مرجعية** من مواد أكتوبر 2026، وليست مرتبطة بالمتجر الحي. سعر «جلسة الأمان» غير معروف فلم يُفترض.
- **الصور**: كل الصور بعد البنر من صور ولاء في مجلد الدرايف «صور للموقع» (10 صور، مقصوصة لمقاسات الموقع). البنر لم يتغير. الأغلفة موزعة حسب نوع التجربة، وليست أغلفة خاصة بكل منتج؛ بعض الصور تتكرر لأن عددها أقل من عدد المنتجات.
- **المفكرات والتدوين، والتوكيدات**: لا منتجات بعد؛ تظهر صفحتها بحالة «قيد التحضير».
- **المعرفة والمصادر**: لا مقالات منشورة بعد.
- **تفاصيل المنتجات**: المدة وطريقة الوصول موثّقة لجلسة «التشافي العاطفي» فقط؛ بقية المنتجات تحيل لصفحتها الأصلية.
- **أماكن اللقاءات الحضورية وتوافرها**: غير متوفرة؛ تُؤكَّد عند الحجز في المتجر الأصلي.
- **الخطوط** من Google Fonts (IBM Plex Sans Arabic وTajawal) فتحتاج اتصالًا بالإنترنت.

## طبقات التنسيق ونظام التصميم

يُحمَّل التنسيق على ثلاث طبقات بهذا الترتيب (الأخيرة تغلب ما قبلها):

1. `public/theme.css` الأساس: العناصر والصفحات الداخلية.
2. `public/redesign.css` هوية التصميم الحالي: الألوان، الهيرو، الأقسام.
3. `public/kit.css` **نظام التقسيم**، مأخوذ من كيتين مقيستين: `toolradar` (الحاوية 1280، إيقاع الأقسام 112، زوايا 8/12/16، أزرار 50/36، بطاقات مسطحة بحد 1px، هيدر 65، شبكات 4/3/2) و`ideeps` (هوامش 16/24/32، زوايا 24 للوحات، حلقة التركيز، حركة 150ms، نافذة بخلفية ضبابية، تنبيه بشريط علوي).

لتغيير المقاسات عدّلي المتغيرات في أعلى `kit.css` (`--container` و`--gutter` و`--sec-gap` و`--r-*` و`--header-h`) وليس القواعد نفسها.

| العنصر | القيمة |
|---|---|
| حاوية المحتوى | حتى 1280، هوامش 16 / 24 (من 640) / 32 (من 1024) |
| المسافة بين الأقسام | 64 / 88 / 112 (جوال / تابلت / كمبيوتر) |
| الأزرار | 50px للإجراءات، 36px للمدمجة، زاوية 8، ضغطة بتصغير 0.95 |
| البطاقات | حد 1px بدون ظل، زاوية 16، شبكة 4 أعمدة (3 من 1279، 2 من 1023) |
| الحقول والتبويبات والآراء | زاوية 12 |
| اللوحات الكبيرة والبانرات | زاوية 24 |
| الهيدر | 65px مع حقل بحث ظاهر من 1100px |

للملف المنفرد `walaa-store-preview.html` يجمع `tools/bundle.ps1` الطبقات الثلاث تلقائيًا.
