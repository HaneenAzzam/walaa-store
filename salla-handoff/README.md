# رفع التصميم على سلة

1. أنشئي قالبًا من Theme Raed (`salla theme create`) وانسخي `assets/` إلى `src/assets/`.
2. استوردي `walaa-redesign.css` (يجمع redesign.css وkit.css) بعد ستايل القالب، وأضيفي خطي Readex Pro وIBM Plex Sans Arabic في `master.twig`.
3. الصقي `home-sections.twig` في `src/views/pages/index.twig` واستبدلي:
   - `CATEGORY-ID` برقم القسم في كل `salla-products-list` (ابدئي من هنا: الجلسات المسجلة أو قسم «الأكثر طلبًا»، والجلسات الخاصة).
   - `CATEGORY-1-URL` إلى `CATEGORY-5-URL`: المسجلة، الحضورية، المفكرات، الخاصة، التوكيدات. و`ABOUT-PAGE-URL` و`FAQ-PAGE-URL`.
   - `ACCESS-FAQ-URL`: رابط صفحة أو سؤال «كيف أصل إلى جلستي بعد الشراء» (خطوة 3 في «كيف تشترين؟»). زر خطوة 2 يفتح سلة المتجر تلقائيًا.
   - اللقاء القادم: `NEXT-NAME` (الاسم)، `NEXT-DATE` (مثل 9 نوفمبر)، `NEXT-DESC` (وصف قصير)، `NEXT-PRICE` (السعر)، `NEXT-URL` (رابط صفحة اللقاء). لا يوجد عدّاد.
   - أسعار البداية في أعلى الملف (`prices`) إذا تغيّرت أسعار المتجر.
4. شغّلي `salla theme preview` وراجعي: بطاقات المنتجات (قد تحتاج تعديل أسماء الفئات في الـCSS)، السلة، الدفع.
5. غير مجرَّب على سلة بعد؛ أسماء مكونات القالب قد تختلف حسب نسخته.

## ترتيب الرئيسية (الإصدار 4، نوفمبر 2026)

مرتّب لتفهم الزائرة المتجر من أول ثوانٍ وتصل للشراء بسرعة:
البنر (ماذا يُباع + سطر ثقة) ← إيش تحتاجي اليوم (مع أسعار البداية) ← ابدئي من هنا (منتجات بزر السلة) ← كيف تشترين (3 خطوات) ← اللقاء القادم ← الجلسات الخاصة ← الأرقام والآراء ← تعرفي على ولاء ← الأسئلة ← الختام.
صورة البنر لم تتغير. حُذفت كتل الترويج المكررة والتبويبات، لأن كل نوع صار له قسمه.
